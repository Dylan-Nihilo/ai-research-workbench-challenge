# AI 信息调研工作台
## 研发实习生工程任务

万象硅芯 · v1.0

### 你要达成的目标

让用户在网页上输入一个调研问题，系统能够自行查找公开资料，借助真实模型完成分析，并在页面上呈现一份结论清楚、可以查看信息来源的调研结果。

例如：比较两种知识库工具，给出适合小团队的选择建议及依据。

### 这个目标背后的工作

完成这个目标，需要打通“理解问题 → 获取资料 → 分析整理 → 展示结果”的过程。请自行拆解任务、选择实现方式，并解决其中的前后端联调和外部服务接入问题。

请使用 Claude 或 Codex 参与开发。应用所需的模型 provider 和资料获取方式由你自行选择、配置和接入，最终需要用真实模型与真实资料完成演示。

### 已提供的起点

仓库提供 React / TypeScript 前端、FastAPI 后端，以及 SQLite 存储。基础页面和任务创建、列表、详情已经可以运行，调研能力尚未接入。

请在这个基础上完成目标。页面如何组织、后端如何处理、各步骤如何衔接，由你决定。

### 完成后交付

提交能够运行的代码、简明的启动与配置说明，以及一次从网页输入问题到查看调研结果的真实演示。简要记录你如何使用 Claude / Codex，以及遇到的关键问题和解决方法。

交付中不要包含真实密钥或私人账号信息。说明尚未完成或尚未验证的部分。
